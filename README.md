# Schlingmann HLF 20 — интерактивная 3D-модель

Модель пожарной машины Feuerwehr Liederbach на шасси MAN TGM 13.290. Страница позволяет рассмотреть машину со всех сторон, открыть четыре двери кабины и семь отсеков оборудования.

## Управление

- Перетаскивание мышью или пальцем — вращение камеры.
- Колесо мыши, жест двумя пальцами или кнопки «+» и «−» — масштаб.
- Нажатие на дверь, шторку или соответствующую кнопку — открыть или закрыть деталь.
- «Открыть всё» и «Закрыть всё» — управление всеми дверями и отсеками.
- «Спереди», «Сзади» и сброс ракурса — управление видом.

## Использование

Откройте `index.html` в современном браузере с поддержкой WebGL. Библиотека 3D, геометрия и материалы встроены в HTML: после скачивания страница работает офлайн. Этот же файл можно разместить на GitHub Pages.

## Точность и источники

Это приблизительная игровая реконструкция по видео и фотографиям. Геометрия, размеры, скрытые детали и часть оборудования восстановлены приблизительно; модель не является точным инженерным чертежом.
